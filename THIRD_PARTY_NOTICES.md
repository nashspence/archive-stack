# Third-party notices

Riverhog depends on and, in some container images, distributes third-party software. Those
components retain their own copyrights and licenses. Riverhog's CAL-1.0 and Apache-2.0 path
assignments do not replace or alter those terms.

This file is intentionally not a hand-maintained dependency inventory. Each tagged release
must generate notices and an SBOM from the exact contents of every wheel and container image,
and distribute them with that artifact. Required static attribution notices, if any arise,
belong here; release-specific dependency inventories do not.
