# Security policy

Security fixes target the current `main` branch and the latest tagged release. Older releases
are unsupported unless their release notes say otherwise.

Report suspected vulnerabilities through GitHub's private vulnerability reporting using
[Report a vulnerability](https://github.com/nashspence/riverhog/security/advisories/new).
Include the affected component and version or source revision, reproduction details, impact,
and any known mitigations. Do not file a public issue or disclose the report publicly before
a fix and disclosure have been coordinated.
